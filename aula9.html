Redes Neurais Profundas O que é Aprendizagem de Máquina? É uma técnica que a partir de dados, rotulados ou não, se torna capaz de associar certos padrões e descobertas com intuito de fazer uma previsão, classificação ou regressão. Alta capacidade de aprender a partir de dados. Facilidade em lidar com problemas complexos.

Redes Neurais Profundas No entanto, técnicas convencionais de Aprendizagem de Máquina são restritas a dados com representação mais simples. Além disso, elas necessitam de dados previamente minerados para o processo de classificação.. Esta restrição é superada por meio de técnicas de Deep Learning .

Redes Neurais Profundas

Redes Neurais Profundas Deep Learning é uma abordagem de redes neurais artificiais (ANN). Redes profundas tem alto nível de abstração e consegue lidar com problemas ainda mais complexos e não-lineares .

Redes Neurais Profundas Deep Learning tem sido aplicado a uma variedade de problemas em diversas áreas, reconhecimento de imagens, fala e processamento de linguagem natural, etc. Com o avanço no desenvolvimento de hardware, o uso de técnicas de Deep Learning tem crescido exponencialmente desde 2006 .

Redes Neurais Profundas A principal técnica é redes neurais convolucionais (CNN). É chamada de convolucional por conta de suas camadas convolucionais que realizam detecção de características locais .

Redes Neurais Profundas Os principais conceitos por trás de CNNs que as fazem tão bem sucedidas são: Conexões locais. Pesos compartilhados. Pooling . Uso de muitas camadas .

Redes Neurais Profundas Uma CNN é composta de um conjunto de componentes e funções que operam nos dados e os modificam. Alguns dos principais componentes são: convolação, rectified linear unit ( ReLU ), pooling , dropout e softmax .

Redes Neurais Profundas Convolução A convolação é um operador linear e o principal operador das CNNs . O objetivo desse operador é gerar um mapa de características.

Redes Neurais Profundas Rectified Linear Unit ( ReLU ) ReLU é o mais simples operador não-linear aplicado após uma filtragem linear. É aplicado a cada pixel do mapa de caracter´ısticas com intuito de retificar valores negativos .

Redes Neurais Profundas Pooling É uma forma de reduzir as dimensões da entrada através do descarte de informação desnecessária e preservação daquelas mais críticas. Ele opera nos canais de características individuais, combinando os valores mais próximos. Os mais comuns são o max-pooling , que retorna os máximos valores de entrada, e o avg-pooling , que retorna os valores médios de entrada .

Redes Neurais Profundas Dropout Foi introduzido com o propósito de evitar over- fit . Ele funciona omitindo metade dos neurônios para cada amostra de treino. Através deste procedimento, cada neurônio tem que trabalhar com uma combinação aleatória de suas entradas. Esta abordagem permite uma melhor generalização para a rede neural .

Redes Neurais Profundas Camada de Achatamento - Flatten É responsável pelo remodelamento, ou achatamento, dos dados de entrada. Isto acontece a partir do colapso de uma matriz bidimensional de características (que possui mais de uma dimensão espacial) em um vetor que pode ser alimentado em um classificador de rede neural totalmente conectado. Os dados aprendidos nas camadas convolucionais são preparados para serem propagados para as camadas totalmente conectadas .

Redes Neurais Profundas Softmax É comumente usada na camada final do classificador. O objetivo é minimizar o erro da função softmax através do ajuste adequado dos pesos dos neurônios da rede neural .

Redes Neurais Profundas Otimizadores para Treinamento Assim como nas Multilayer Perceptrons , as CNNs são treinadas utilizando Gradiente Descendente (GD) e Backpropagation

  • O objetivo é ajustar os parâmetros (pesos) de forma a diminuir a diferença entre a saída esperada e a saída obtida
  • Esta diferença é medida através de uma função de custo.

Redes Neurais Profundas Funções de custo mais utilizadas para Treinamento Para tarefas de classificação: Softmax Cross Entropy

  • Sigmoid Cross
  • Para tarefas de regressão : Mean Squared Error (MSE).

Redes Neurais Profundas Otimizadores para Treinamento Variantes do Gradient Descent : ○ Batch Gradient Descent ○ Stochastic Gradient Descent (SGD) ○ Mini-batch Gradient Descent Ajuste automático da taxa de aprendizado: ○ Adaptive Gradient Algorithm (ADAGRAD) ○ ADADELTA ○ Adaptive Moment Estimation (Adam) ○ RMSProp Outros: ○ SGD with Momentum ○ Nesterov Accelerated Gradient (NAG )

Redes Neurais Profundas Batches Durante o treinamento, é comum passar um ‘pacote’ de dados para o modelo. Evita a necessidade de realizar o ajuste de pesos a cada novo dado (computacionalmente custoso). Valores típicos para o tamanho do batch: 32 ~ 256 instâncias. Para calcular o custo de um batch, utiliza-se a média dos custos de cada dado dentro do batch .

Redes Neurais Profundas Batches

Redes Neurais Profundas Iterações e épocas de treinamento Iteração: um ajuste de pesos (normalmente no fim de um batch). Época: um ciclo completo no conjunto de treinamento (todos os batches ).

Redes Neurais Profundas Como Avaliar um CNN Conjuntos de treinamento, validação e teste ○ Hold -Out ○ K- fold Cross validation Métricas de avaliação: ○ Matriz de confusão ○ True Positive, True Negative, False Positive, False Negative ○ Acurácia, especificidade, sensibilidade Avaliação visual: ○ Comportamento das curvas de erro e custo

Redes Neurais Profundas Hold -out e K- fold Cross Validation Hold -out consiste em separar os dados em três conjuntos exclusivos: treinamento, validação e teste. Exemplo: 60%, 20%, 20%. K- fold Cross Validation consiste em criar K partições de treinamento/teste, de forma a obter uma análise estatística mais relevante do erro .

Redes Neurais Profundas Métricas de avaliação - Matriz de confusão Tabela onde um eixo representa a classe real e o outro representa as classes preditas pelo classificador.

Redes Neurais Profundas Métricas de avaliação True positive (TP) , ou verdadeiros positivo: quando o classificador acerta a classe do objeto

  • True negative (TN ), ou verdadeiro negativo: quando o classificador rejeita um objeto corretamente
  • False positive (FP), ou falso positivo: quando o classificador erra a classe de um objeto (alarme falso)
  • False negative (FN), ou falso negativo: quando o classificador rejeita um objeto erroneamente

Redes Neurais Profundas Métricas de avaliação

Redes Neurais Profundas Métricas de avaliação ● Acurácia : TP + TN / TP + TN + FP + FN Não é uma boa métrica para datasets desbalanceados ● Sensibilidade: TP / TP + FN ● Especificidade: TN / TN + FP O produto da sensibilidade pela especificidade é uma boa métrica de avaliação para datasets desbalanceados.
