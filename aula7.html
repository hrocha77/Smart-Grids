Microgrids São sistemas de distribuição de eletricidade que contêm cargas e recursos de energia distribuídos (como geradores distribuídos, dispositivos de armazenamento ou cargas controláveis) Operam de forma controlada e coordenada, quando conectado à rede de energia principal ou isolada. Pode desconectar da rede tradicional e operar de forma autônoma .

Microgrids

Virtual Power Plants ( VPPs ) É um novo modelo de infraestrutura de energia que consiste na integração de diferentes tipos de GDs controlados por um sistema de gerenciamento de energia (EMS) Virtual. É composta por um controle centralizado de diferentes grupos de GDs ou Microgrids , chamados de clusters. Cada um destes clusters é controlado por uma estação de gerenciamento local (Local Management Station (LMS)).

Virtual Power Plants ( VPPs )

Virtual Power Plants ( VPPs ) O LMS tem informações sobre os requisitos de energia dos usuários conectados ao seu cluster.

Virtual Power Plants ( VPPs ) O EMS recebe as informações de cada LMS e define a entrada ou saída de energia de cada cluster na rede. Com a informação da EMS, o LMS configura o cluster para que ele entre em funcionamento ou fique em standby . O EMS pode priorizar o uso de recursos de energia distribuídos ( DERs ) ao invés do uso de combustíveis fósseis.

Virtual Power Plants ( VPPs ) Os benefícios da VPP : Otimização do rendimento de utilização de toda a rede

  • Alta confiabilidade da produção de energia, ao controle total da rede para atingir o principal objetivo da EMS
  • Alta velocidade necessária para acompanhar as mudanças rápidas na demanda do sistema e a alta integração dos DERs .

Variable Neighborhood Descent / Search (VND/VNS) Proposto por Mladenovic & Hansen no qual, efetua-se uma sequência de buscas locais e troca-se a estrutura de vizinhança durante a busca.

Variable Neighborhood Descent (VND) Sejam uma solução inicial x, um conjunto de vizinhanças factíveis N k (x), k = 1, ..., kmax e para cada vizinhança N k (x), disponha de um método de busca local. O VND varia a vizinhança de x na ordem estipulada: N 1 (x), N 2 (x), ... Em uma vizinhança N k (x), se a busca local encontra x’ melhor que x, substituímos x por x’ e voltamos à vizinhança N 1 , Caso contrário, passamos à vizinhança N k+1 (x ).

Variable Neighborhood Descent (VND) As vizinhanças devem ser ordenadas de modo que primeiras envolvam movimentos mais fáceis, assim o gasto computacional cresce quando mudamos de vizinhança. Em cada vizinhança N k (x), podemos encontrar o melhor ponto, x* ( best improvement ) ou o primeiro ponto x’ tal que f(x’) < f(x) ( first improvement ).

Variable Neighborhood Search Básico (VNS) VNS Geral: Combina o VNS básico com o emprego do VND como algoritmo de busca local. VNS enviesado ( skewedVNS ): Muitas vezes, é necessário explorar vales distantes do ponto atual. Mas gerar pontos aleatórios distantes é o mesmo que adotar recomeços (o que nem sempre é eficiente). Neste caso, adota-se uma regra para aceitar pontos: x” é aceito se f(x”) < f(x) + α ρ (x, x”) onde α > 0 é uma constante e ρ (x, x”) é uma função que mede a distância entre x e x”.
