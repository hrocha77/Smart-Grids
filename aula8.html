Redes Neurais Artificiais ( RNAs )

Redes Neurais Artificiais ( RNAs ) Técnica inspirada no funcionamento do cérebro, onde neurônios artificiais, conectados em rede, são capazes de aprender e de generalizar.

Redes Neurais Artificiais ( RNAs ) Resolve problemas no qual exista incerteza sobre um dado fenômeno

  • É usado para: Classificação Regressão Análise de Agrupamentos (clusters ).

Redes Neurais Artificiais ( RNAs ) Classificação É a atribuição de casos ou instâncias de dados a uma ou mais possíveis classes. Regressão É a estimativa do valor de uma variável baseada em exemplos .

Redes Neurais Artificiais ( RNAs ) Evolução das RNAs 1940-1950: início das Redes neurais com McCulloch e Pitts . 1950-1960: Perceptron de aprendizado supervisionado. 1960-1970: Pouco avanço. 1980-2000: Redes simétricas e Backpropagation . 2006-20XX : Redes Neurais Profundas.

Redes Neurais Artificiais ( RNAs )

Redes Neurais Artificiais ( RNAs ) Resumo do funcionamento Apresentação de um conjunto de valores que representam as variáveis de entrada do neurônio

  • Multiplicação de cada entrada do neurônio pelo seu respectivo peso sináptico Obtenção do potencial de ativação produzido pela soma ponderada dos sinais de entrada, subtraindo-se o limiar de ativação Aplicação de uma função de ativação apropriada, tendo-se como objetivo limitar a saída do neurônio Compilação da saída a partir da aplicação da função de ativação neural em relação ao seu potencial de ativação .

Redes Neurais Artificiais ( RNAs ) Funções de ativação

Redes Neurais Artificiais ( RNAs ) Arquitetura Define a forma como os seus diversos neurônios estão arranjados, ou dispostos, uns em relação aos outros. Os arranjos são estruturados através do racionamento do fluxo sináptico. Disposição de seus neurônios

  • Formas de interligação entre os neurônios
  • Constituição de suas camadas.

Redes Neurais Artificiais ( RNAs ) Arquitetura Arquitetura feedforward (alimentação à frente)

  • Arquitetura recorrente
  • Arquitetura reticulada .

Redes Neurais Artificiais ( RNAs ) Arquitetura feedforward com Camada simples Constituída de uma camada de entrada e única camada de neurônios, que é a própria saída. Fluxo de informações segue numa única direção. Ex : Perceptron , Adaline . Aplicações : classificação de padrões, filtragem linear. .

Redes Neurais Artificiais ( RNAs ) Arquitetura feedforward com Camadas múltiplas Quantidade de camadas escondidas e de neurônios dependem, do tipo e complexidade do problema. Aplicações : aproximação de funções, classificação de padrões, controle de processos, otimização, etc. .

Redes Neurais Artificiais ( RNAs ) Arquitetura recorrente ( Ex : Hopfield ) Saídas dos neurônios são realimentadas como sinais de entrada para outros neurônios. • Realimentação as qualificam para processamento dinâmico de informações. • Aplicação em previsão, otimização, controle, etc .

Redes Neurais Artificiais ( RNAs ) Arquitetura reticulada ( Ex : Kohonen ) Levam em consideração a forma em que a disposição espacial dos neurônios está organizada. • Visa propósitos de extração de características. • Aplicações: problemas de agrupamento, classificação de padrões, otimização, etc .

Redes Neurais Artificiais ( RNAs ) Topologia Define as diferentes formas de composições estruturais que uma rede pode assumir, dada uma determinada arquitetura. Processo de treinamento Consiste na aplicação de um conjunto de passos ordenados com o intuito de ajustar os pesos e os limiares de seus neurônios. Objetivo final: generalização de soluções (as quais não eram conhecidas ).

Redes Neurais Artificiais ( RNAs ) Processo de treinamento

Redes Neurais Artificiais ( RNAs ) Tipos de treinamento Treinamento supervisionado

  • Cada amostra de treinamento é então composta pelos sinais de entradas e suas correspondentes saídas. Comporta como se houvesse um “professor” ensinando para a rede qual seria a resposta correta para cada amostra apresentada.

Redes Neurais Artificiais ( RNAs ) Tipos de treinamento Treinamento supervisionado Apresente uma amostra de treinamento. Calcule a saída produzida pela rede. Compare com a saída desejada. Se estiver dentro de valores aceitáveis termine o processo de aprendizado, senão ajuste os pesos sinápticos e limiares dos neurônios e volte ao passo 1 .

Redes Neurais Artificiais ( RNAs ) Treinamento com o algoritmo backpropagation O backpropagation é indiscutivelmente o algoritmo mais importante na história das redes neurais. O passo para frente ( forward pass ), as entradas são passadas através da rede e as previsões de saída obtidas . 2. O passo para trás ( backward pass ), onde calcula o gradiente da função de perda na camada final da rede e usa esse gradiente para aplicar recursivamente a regra da cadeia ( chain rule ) para atualizar os pesos da rede ( retro-propagação ).

Redes Neurais Artificiais ( RNAs )

Redes Neurais Artificiais ( RNAs ) Tipos de treinamento Treinamento não-supervisionado Diferentemente do supervisionado, as respectivas saídas desejadas são inexistentes. A rede deve se auto-organizar em relação às particularidades existentes entre os elementos do conjunto total de amostras, identificado subconjuntos (clusters) que contenham similaridades.

Redes Neurais Artificiais ( RNAs ) Tipos de treinamento Treinamento não-supervisionado Passos do treinamento não supervisionado: 1. Apresente todas as amostras de treinamento. 2. Obtenha as características que marcam as amostras de treinamento. 3. Agrupe todas as amostras com características em comum. 4. Coloque as amostras comuns em classes .

Redes Neurais Artificiais ( RNAs ) Exemplo: XOR for i = 1:iterations out = zeros(4,1)

  • numIn = length (input(:,1))
  • for j = 1:numIn % Hidden layer H1 = bias(1,1) * weights (1,1) + input(j,1) * weights (1,2) + input(j,2) * weights (1,3)
  • % Send data through sigmoid function 1/1+e^-x % Note that sigma is a different m file % that I created to run this operation x2(1) = sigma(H1)

Redes Neurais Artificiais ( RNAs ) Exemplo: XOR H2 = bias(1,2)* weights (2,1) + input(j,1)* weights (2,2) + input (j,2) * weights (2,3)

  • x2(2 ) = sigma(H2)
  • % Output layer x3_1 = bias(1,3)* weights (3,1) + x2(1)* weights (3,2) + x2(2 )* weights (3,3)
  • out(j ) = sigma(x3_1)
  • % For output layer : % delta( wi ) = xi*delta, % delta = (1- actual output)* ( desired output - actual output) delta3_1 = out(j)*(1-out(j))*(output(j)-out(j))
  • % Propagate the delta backwards into hidden layers delta2_1 = x2(1)*(1-x2(1))* weights (3,2)*delta3_1
  • delta2_2 = x2(2)*(1-x2(2))* weights (3,3)*delta3_1

  • weights (3,k) = weights (3,k) + coeff *bias(1,3)*delta3_1
  • else % When k=2 or 3 input cases to neurons weights (1,k) = weights (1,k) + coeff *input(j,1)*delta2_1
  • weights (2,k) = weights (2,k) + coeff *input(j,2)*delta2_2
  • weights (3,k) = weights (3,k) + coeff *x2(k-1)*delta3_1
