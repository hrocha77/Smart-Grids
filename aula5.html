Estimação de Estado (EE ) Algoritmo: 1. Entrar com os dados da rede e medição

  • 2. Montar a matriz Y
  • 3. Inicializar o índice de iteração k
  • 4. Inicializar o vetor de estado x k
  • 5. Montar a matriz H( x k )
  • 6. Calcular a matriz G( x k )=H T ( x k )R -1 H( x k )
  • 7. Calcular o vetor h( x k )
  • 8. Calcular o vetor g( x k )= H T ( x k )R -1 (z -h( x k ))
  • 9. Calcular o vetor de estado x k+1 = x k +G ( x k ) -1 *g( x k )
  • 10. Testar convergência: | x k+1 - x k |< €
  • 11. Se não convergiu, faca x k =x k+1 e k=k+1 e volte ao passo 5. Se convergiu, fim.

Estimação de Estado (EE ) Níveis Críticos de Redundância Durante a operação, níveis inferiores de redundância são atingidos. Tais níveis, podem acarretar problemas ao estimador . 1º Nível: perda de qualidade do estado e medidas estimadas

  • 2º Nível: presença de conjuntos críticos
  • 3º Nível: presença de medidas críticas, a perda de observabilidade torna-se iminente

Estimação de Estado (EE ) Níveis Críticos de Redundância Medida Crítica ( Cmed ) Não são detectadas e nem identificadas

  • Essenciais para a observabilidade
  • Não são afetadas pela filtragem
  • Os r esíduos e os desvios são sempre nulos.

Estimação de Estado (EE ) Níveis Críticos de Redundância Conjunto Crítico ( Cconj ) São detectadas mas não identificadas

  • Na perda de uma, as demais se tornam Críticas
  • Formado por medidas fortemente correlacionadas
  • Os r esíduos normalizados são iguais e a correlação entre eles é máxima (=1).
